# 월하검 · Moonlit Blade

달빛 아래 대나무 숲에서 끝없이 찾아오는 적과 겨루는 브라우저 칼싸움 게임입니다.
HTML Canvas와 JavaScript로 만들어 별도 설치나 빌드 없이 실행할 수 있습니다.

## 실행

`index.html`을 브라우저에서 여세요. 인터넷 연결이 없어도 플레이할 수 있으며, Google Fonts를 불러오지 못하면 기본 글꼴을 사용합니다.

## 조작

| 조작 | 기능 |
| --- | --- |
| WASD / 방향키 | 이동 |
| J / 짧은 좌클릭 | 근접 베기 |
| 좌클릭 0.8초 누르기 | 월광 폭발: 주변 적 공격 및 밀쳐내기 |
| L | 관통형 원거리 참격 |
| K / 마우스 우클릭 누르기 | 방어 |
| 스페이스 | 순간 무적 대시 |
| P / Esc | 일시정지 및 재개 |

마우스 또는 이동 방향으로 조준합니다. 모바일에서는 화면의 이동·베기·참격·방어·대시 버튼을 사용할 수 있습니다. 충전형 광역기는 마우스 좌클릭으로 사용합니다.

## 전투

- 근접 베기 3회 연속 명중: 금빛 칼날, 공격력 2배.
- 근접 베기 6회 연속 명중: 푸른빛 칼날, 공격력 3배.
- 헛치거나 피해를 받으면 강화가 초기화됩니다.
- 강화는 참격과 월광 폭발에도 적용됩니다. 두 스킬은 연속 명중 횟수를 바꾸지 않습니다.
- 참격: 기력 25 소모, 재사용 1초.
- 월광 폭발: 기력 45 소모, 재사용 5초. 한 번 누르고 있는 동안 한 번만 발동합니다.
- 적의 붉은 공격 예고를 보고 방어하거나 피하세요. 정확한 타이밍의 방어는 반격으로 이어집니다.
- 다음 웨이브에서 체력이 15 회복되며, 웨이브가 오를수록 적이 강해집니다.
- 최고 기록은 브라우저에 저장됩니다.

## 테스트

Node.js가 설치되어 있다면 다음 명령으로 전투 로직을 점검할 수 있습니다.

```sh
node test.cjs
```

## 파일

- `index.html`: 게임 화면과 조작 안내
- `style.css`: 화면 구성과 반응형 스타일
- `game.js`: 전투, 적 AI, 이펙트, 입력 처리
- `test.cjs`: 외부 라이브러리 없는 전투 로직 테스트
